
Сервисы для трейсинга:

- CRM
- CRM API
- Massages Queue
- MES API

Мотивация:

Трейсинг позволит выявить задержку которая может происходить по мере прохождения заявки на изготовление 
ювелирного изделия по микросервисам. Также на каждом этаме можно измерять время обработки задачи.

Бизнес-метрики замеряемые трейсингом:
- время обработки заказа
- выяление наиболее нагруженных микросервисов в цепочке обработки заказа
- среднее время выполнения заказов

Предлагаемое решение:
Ссылка на доработанную архитектуру https://drive.google.com/file/d/1EiToAq4LT2X74sqI9ZEs6COLTz3lBA1l/view?usp=sharing

Компромиссы:

Трейсинг не имеет смысла внедрять когда нет достаточно длинных цепочек взаимодействий между микросервисами

Аспекты безопасности:

Возможно внедрение технологии Active Directory для централизованного хранения и управления учетными записями в кампании.
(все учетки разбиты на группы с соотвествующими правами доступа)

Из минусов -> финансовые расходы на внедрение и поддержку
